# sport-sections-club

Лабораторные работы по курсу «Проектирование сетевых приложений» (JavaScript), 5 семестр.

**Тема:** Запись в спортивные секции клуба. `Услуги` — спортивные секции (вид спорта, тренер, возраст, стоимость в месяц), `заявки` — заявка спортсмена на запись в набор секций.

**Визуальный стиль:** сайт Центрального спортивного клуба армии — [cska.ru](https://cska.ru).

**Выполнил:** Крючков Даниил Игоревич, ИБМ3-54Б.
